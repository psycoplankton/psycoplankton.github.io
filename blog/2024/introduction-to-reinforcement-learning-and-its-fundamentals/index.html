What is reinforcement learning? Have you played that game with a bouncy red ball, in which we have to make that ball reach the finish line but there are so many obstacles like a wall, or some needles which we have to skip to survive. If yes, then can you think of a way to teach a machine to play that game🤔?

The answer to the above question is Reinforcement learning. As the name suggests, you learn by reinforcing. Better yet, you learn by the mistakes you make and get rewarded for the correct steps you take.

Reinforcement Learning is the science an framework of learning and making decisions by interaction. Some examples of reinforcement learning problems are to teach a program:

  1. How to fly a helicopter.
  2. Manage an investment portfolio.
  3. Control a power Station.
  4. Make a robot walk.
  5. play video games(like the one I talked about in the beginning).

RL(short for Reinforcement Learning) is based on the reward hypothesis. Any goal can be formalized as the outcome of maximizing a cumulative reward. Thus for each of the above examples, we can stipulate a reward and apply the principles of RL.

Formalizing a RL problem requires to think about:

  1. time
  2. Consequences of actions.
  3. actively gather experience.
  4. predicting the future.
  5. dealing with uncertainity.

Formalizing the RL Problem

At each time step t, the agent:

  1. receives observation Oₜ (and reward Rₜ ).
  2. executes an action Aₜ.

The Environment, on the other hand:

  1. Receives the action Aₜ.
  2. emits observation Oₜ₊₁.

A reward is a scalar feedback that comes from the environment at each time-step and it helps the agent understand the impact of its action on the environment. This basically indicated the performance of the agent.

The agent’s job is to maximize the cumulative reward Gₜ = Rₜ + Rₜ₊₁ + Rₜ₊₂ + … . . It has only the future rewards and not the past rewards. The reason for this is, the rewards that have already been collected and observed, changing them will cause nothing good for us, that is why we only consider the future rewards. Basically the logic is that the future should be optimal from the current time-step. Sometimes Gₜ is also called return.

The expected cumulative reward from the state Sₜ=s is called the value v(s).

Value depends on the actions the agent takes. Goal is to maximize value by picking suitable actions. Rewards and values define utility of each states and action.
